# LLM From Scratch 학습 기록

책의 원본 코드는 루트의 `ch02/` ~ `ch07/`에서 참고하고, 직접 작성한 코드와 학습 기록은 이 폴더에 보관합니다.

## 시작하기

- `ch02/practice.ipynb`: 2장 직접 구현과 실험
- `ch02/notes.md`: 이해한 내용, 질문, 실험 결과
- 다음 장을 시작할 때 같은 구조로 폴더를 추가합니다.

## 학습 순서

1. 책의 한 절을 읽습니다.
2. 작은 단위로 직접 구현합니다.
3. 실행 전에 출력과 텐서의 shape를 예상합니다.
4. 매개변수 하나를 바꿔 결과를 비교합니다.
5. 원본 코드와 비교하고 배운 내용을 기록합니다.

노트북을 다른 폴더에서 실행하면 데이터 파일의 상대 경로가 달라질 수 있습니다. 원본 코드의 파일 경로를 확인하고 실습 위치에 맞게 조정하세요.

환경 설정은 루트의 `setup/README.md`를 참고하세요. 큰 데이터와 모델 체크포인트는 `study/data/`, `study/checkpoints/`, `study/outputs/`에 보관하며 Git에서 제외합니다.

원본 저장소: https://github.com/rasbt/LLMs-from-scratch

Git 원격 저장소는 `origin`을 개인 학습 저장소로, `upstream`을 책 원본 저장소로 사용합니다.
